Recovery / สำรอง ECU

เก็บข้อมูลจากกล่องเป็นไฟล์ก่อนแก้อะไรทุกครั้ง
1) สำรองตารางข้อมูล ECU (ใช้ได้แล้ว)

อ่านทุกตารางวินิจฉัยที่กล่องยอมให้อ่าน (0x00–0xFF) พร้อมรหัส ECU เก็บเป็นไฟล์ในคลัง ใช้ระบุรุ่นกล่อง และเป็นข้อมูลสำหรับเพิ่มรองรับรุ่นใหม่

2) อ่านไฟล์แมพเต็มจากกล่อง (Full read) 🔒

การอ่าน/เขียนหน่วยความจำแฟลชใช้คำสั่ง bootloader ที่ต่างกันในแต่ละรุ่นกล่อง (Keihin / Shindengen / Denso / Continental) จะเปิดให้ใช้ทีละรุ่นหลังทดสอบกับกล่องจริงแล้ว

ส่งไฟล์จากข้อ 1 + รหัสบนกล่อง ECU (เช่น 38770-K0W-T01) มา เพื่อเพิ่มรุ่นนั้นเข้าโปรแกรม

Fast Flash / Flash Remap

เขียนแมพใหม่ลงกล่อง
🔒 ยังล็อกไว้สำหรับทุกรุ่น
ถ้าเขียนลงกล่องผิดวิธี กล่องจะ “ดับ” (brick) รถสตาร์ทไม่ติด โปรแกรมจะเปิด Flash ให้เฉพาะรุ่นกล่องที่ผ่านขั้นตอนนี้ครบ:
⬜เชื่อมต่อกล่องได้ และอ่านรหัส ECU ได้
⬜มีไฟล์สำรองต้นฉบับของกล่องนี้ (Full read) เก็บในคลัง
⬜ยืนยันโปรโตคอล bootloader ของรุ่นกล่องนี้กับกล่องจริงแล้ว
⬜ไฟล์ที่จะเขียนมาจากกล่องรุ่นเดียวกัน และ checksum ถูกต้อง
⬜แบตเตอรี่ ≥ 12.4V (แนะนำต่อเครื่องชาร์จระหว่าง Flash)

รุ่นที่ยืนยันแล้ว: ยังไม่มี

ความต้องการ
• ใช้ Google Chrome หรือ Microsoft Edge บนคอม (Windows / Mac / Linux) — รองรับ Web Serial
• สาย USB K-line ที่ใช้ชิป FTDI FT232, CH340, CP210x หรือ PL2303 (ลงไดรเวอร์ให้เห็นเป็น COM port ก่อน)
