คู่มือเริ่มต้นใช้งาน
  1. เปิดใช้แบบต่อรถ: ใช้ Chrome หรือ Edge บนคอม · ถ้าเปิดผ่านลิงก์แล้วต่อสายไม่ได้ ให้รันในเครื่องด้วย start-windows.bat
  2. เชื่อมต่อ: เสียบสาย เปิดกุญแจ (ไม่ต้องติดเครื่อง) กดเชื่อมต่อ → สาย USB/COM แล้วเลือกพอร์ต · ลองก่อนได้ด้วย ECU จำลอง
  3. ตรวจรถ: Live Data ดูค่าสด · รหัสปัญหา DTC อ่าน/ลบ · สำรองกล่องก่อนแก้ทุกครั้ง
  4. จูน: เปิดไฟล์ .bin → ค้นหาแมพอัตโนมัติ หรือเปิด XDF ของรุ่นนั้น → แก้ตาราง หรือใช้ “จูนด่วน” → ตรวจ/แก้ checksum → Flash (ยังล็อก)
  5. จูนด้วย AF: Live หน้า 2 เลือกแมพ กดเริ่มเก็บข้อมูล ขี่ให้ครบช่วง แล้วกดนำค่าแนะนำไปใช้
  6. Dyno: Live หน้า 3 กดพร้อมวัดแล้วเร่งสุด เทียบก่อน/หลังจูน
  7. ส่งรถ: หน้าใบส่งรถ กรอกข้อมูลแล้วสร้าง ระบบดึง Dyno/DTC มาให้
