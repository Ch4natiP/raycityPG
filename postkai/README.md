# โพสต์ขาย

แอปสำหรับแม่ค้าออนไลน์: ถ่ายรูปสินค้า แล้วได้รูปพร้อมโพสต์ และแคปชันขายของภาษาไทยสำหรับ Facebook, TikTok, Shopee/Lazada และ LINE

## ใช้งานได้ตอนนี้
- ถ่ายรูปหรือเลือกรูป แล้วเลือกพื้นหลัง (รูปเดิม หรือกรอบสี 6 สี) ใส่ป้ายราคาและชื่อร้านบนรูป
- ปุ่มลบพื้นหลังเดิม (ทดลอง) ทำงานบนมือถือเอง ไม่ต้องอัปโหลดรูป
- AI (Claude) ดูรูปแล้วเขียนแคปชันตามโทนที่เลือก พร้อมแฮชแท็กและช่วงราคาตลาดโดยประมาณ
- ใช้ฟรีวันละ 3 ครั้งต่อเครื่อง และใช้ได้ไม่จำกัดเมื่อกรอกรหัส Pro
- บันทึกรูป แชร์ และคัดลอกข้อความได้ในปุ่มเดียว
- ติดตั้งลงหน้าจอมือถือได้ (PWA)
- **โหมดตัวอย่าง:** ถ้าเปิดหน้าเว็บโดยไม่มีเซิร์ฟเวอร์ (เช่น GitHub Pages) แอปจะใช้แม่แบบข้อความแทน AI เอาไว้โชว์ลูกค้าได้

## วิธีรัน
```bash
cd postkai
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
# เปิด http://localhost:8787
```

ตั้งค่าเพิ่มได้ด้วยตัวแปรเหล่านี้:
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `FREE_PER_DAY` | `3` | จำนวนครั้งที่ใช้ฟรีต่อวันต่อเครื่อง |
| `PRO_CODES` | ว่าง | รหัส Pro คั่นด้วยจุลภาค เช่น `AB12,CD34` |
| `POSTKAI_MODEL` | `claude-opus-5-5` | โมเดลที่ใช้เขียนแคปชัน |
| `PORT` | `8787` | พอร์ตของเซิร์ฟเวอร์ |

## ต้องทำก่อนเปิดให้คนทั่วไปใช้
- ย้ายตัวนับโควตาฟรีจากหน่วยความจำไปเก็บในฐานข้อมูล (ตอนนี้รีสตาร์ตเซิร์ฟเวอร์แล้วตัวนับจะเริ่มใหม่ และคนล้างข้อมูลเบราว์เซอร์ก็ได้สิทธิ์ใหม่)
- ระบบจ่ายเงิน Pro ผ่านพร้อมเพย์ที่ออกรหัสให้อัตโนมัติ
- นโยบายความเป็นส่วนตัว (PDPA)
- ทดลองต้นทุน AI ต่อโพสต์กับรูปจริงก่อนตั้งราคา Pro
