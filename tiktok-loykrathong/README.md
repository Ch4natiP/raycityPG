# 🪷 ลอยกระทงออนไลน์ — TikTok LIVE

ฉากไลฟ์แนวตั้ง (1080×1920) ที่ให้ผู้ชมใน TikTok LIVE ลอยกระทงได้ผ่านคอมเมนต์และของขวัญ

| ผู้ชมทำอะไร | ในไลฟ์จะเกิดอะไร |
|---|---|
| เข้าห้อง | มีตัวละครชื่อของผู้ชมโผล่บนท่าน้ำ |
| พิมพ์ `ลอย` หรือ `ลอยกระทง` | ลอยกระทงใบตองฟรี 1 ใบ (ลอยซ้ำได้ทุก 8 วินาทีต่อคน) |
| พิมพ์ `ลอย ขอให้สอบผ่าน` | ลอยกระทง และขึ้นคำอธิษฐานบนจอ |
| พิมพ์ `ชาย` / `หญิง` | เปลี่ยนตัวละครของตัวเอง |
| พิมพ์ `สวัสดี` | ตัวละครยกมือไหว้ |
| ส่งของขวัญ | ลอยกระทงพิเศษตามราคาของขวัญ (จำนวนเท่ากับที่ส่ง) |
| ของขวัญ 99+ เหรียญ | กระทงทองคำ และจุดพลุ |
| ของขวัญ 500+ เหรียญ | กระทงยักษ์ จุดพลุ และปล่อยโคมลอย |
| กดไลค์ | หัวใจลอยขึ้น และยิงพลุทุกครั้งที่ไลค์รวมครบ 300 |
| ติดตาม / แชร์ | ตัวละครกระโดดดีใจ และขึ้นข้อความขอบคุณ |

บนจอยังมีกล่องคำอธิษฐานล่าสุด, Top 5 ผู้ร่วมลอยกระทง และแถบเป้าหมายจำนวนกระทง
ตั้งค่าทุกอย่างนี้ได้จากหน้าควบคุม

## วิธีใช้

1. ติดตั้ง [Node.js](https://nodejs.org) (เลือกรุ่น LTS)
2. เปิดโปรแกรม
   - **Windows**: ดับเบิลคลิก `start-windows.bat`
   - **Mac**: ดับเบิลคลิก `start-mac.command`
   - หรือพิมพ์ `npm install` แล้วตามด้วย `npm start`
3. หน้าควบคุมจะเปิดขึ้นที่ http://localhost:3000
   - ใช้แท็บ **🧪 ทดสอบ** ลองกดดูก่อนได้เลย โดยยังไม่ต้องไลฟ์
4. ใส่ฉากเข้าไลฟ์ โดยใช้ลิงก์ฉาก **http://localhost:3000/overlay**
   - **OBS**: เพิ่ม Source แบบ *Browser*, ตั้งขนาด 1080×1920 แล้วติ๊ก *Control audio via OBS* ถ้าต้องการเสียง จากนั้นไลฟ์ขึ้น TikTok ด้วย Stream Key
   - **TikTok LIVE Studio**: ถ้ามีแหล่งที่มาแบบลิงก์ ให้วางลิงก์ฉากได้เลย ถ้าไม่มี ให้กด "เปิดหน้าต่างใหม่" ในหน้าควบคุม แล้วใช้ *จับภาพหน้าต่าง (Window capture)*
5. **เริ่มไลฟ์ใน TikTok ก่อน** แล้วค่อยใส่ชื่อบัญชีในแท็บ 🚀 เริ่มไลฟ์ และกด **เชื่อมต่อ**

## หมายเหตุ

- การรับคอมเมนต์และของขวัญใช้ไลบรารี [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector) ซึ่งไม่ใช่ API ทางการของ TikTok
  - ถ้า TikTok เปลี่ยนระบบ อาจเชื่อมต่อไม่ได้ชั่วคราว แก้ได้ด้วย `npm update tiktok-live-connector`
  - ไลบรารีใช้บริการ sign ของ eulerstream.com ซึ่งใช้ฟรีได้แต่มีโควตา ถ้าโดนจำกัดบ่อย ให้สมัคร API key แล้วใส่ใน "ตัวเลือกขั้นสูง"
- จำนวนกระทง อันดับ และคำอธิษฐาน จะถูกบันทึกไว้ที่ `data/state.json` ส่วนการตั้งค่าอยู่ที่ `data/config.json`
  - ปิดโปรแกรมแล้วเปิดใหม่ ข้อมูลยังอยู่
  - กด "ล้างข้อมูล" ในแท็บทดสอบเมื่อต้องการเริ่มใหม่
- หน้าตัวอย่างในหน้าควบคุมจะปิดเสียงไว้ เพื่อไม่ให้เสียงดังซ้ำกับ OBS

## ไฟล์

- `server.js`: เชื่อม TikTok LIVE, คำนวณคะแนนและกระทง แล้วส่งให้ฉากผ่าน WebSocket
- `public/overlay.html` และ `overlay.js`: ฉากแม่น้ำเจ้าพระยา วาดด้วย canvas ล้วน ไม่ต้องใช้รูปภาพ
- `public/index.html`: หน้าควบคุม
