# ⚡ PG Performance ECU Tuner

โปรแกรมจูน/วินิจฉัยกล่อง ECU มอเตอร์ไซค์ผ่านสาย USB K-line ใช้ได้ทั้งบนคอม (PC/Mac) และติดตั้งเป็นแอปได้

## สถานะแต่ละเมนู

| เมนู | สถานะ |
|---|---|
| **Live Data** (รอบ, TPS, อุณหภูมิ, MAP, แบต, ความเร็ว, เวลาฉีด, องศาไฟ, O2) + กราฟ + บันทึก CSV | ✅ Honda PGM-FI |
| **วินิจฉัย DTC** (อ่านรหัสปัจจุบัน/ประวัติ + ความหมายภาษาไทย, ลบรหัส) | ✅ Honda PGM-FI |
| **TabTuner** (เปิด .bin, ตารางสีแบบ heatmap, ลากเลือก, ±%, ตั้งค่า, คืนค่า, แก้ checksum, hex viewer) | ✅ ทุกยี่ห้อ (ทำงานกับไฟล์) |
| **Recovery: สำรองตาราง ECU** (อ่านทุกตาราง 0x00–0xFF + รหัสกล่อง) | ✅ Honda PGM-FI |
| **Recovery: อ่านแฟลชเต็ม / Flash Remap** | 🔒 ล็อกไว้ จนกว่าจะยืนยันโปรโตคอล bootloader กับกล่องจริงทีละรุ่น |
| **คลังไฟล์** (เก็บ bin / log / backup ในเครื่อง) | ✅ |
| **Terminal** (ส่ง/ดูไบต์ดิบ ใช้ดักโปรโตคอลยี่ห้ออื่น) | ✅ |
| Yamaha / KWP2000 | ⏳ ยังไม่รองรับ (ใช้ Terminal เก็บข้อมูลไว้ก่อนได้) |

> ตัวถอดค่า Live Data และ DTC ของ Honda อ้างอิงข้อมูลที่ชุมชนแกะไว้ (เช่นโปรเจกต์ HondaECU)
> แต่ละรุ่นกล่องอาจต่างกันเล็กน้อย โปรแกรมจึงแสดงไบต์ดิบใต้ทุกค่า เอาไว้เทียบกับเครื่องสแกนตัวอื่น

## วิธีใช้

1. ลงไดรเวอร์สาย USB ให้ Windows เห็นเป็น COM port (FTDI FT232 / CH340 / CP210x / PL2303)
2. ดับเบิลคลิก `start-windows.bat` (ต้องมี [Node.js](https://nodejs.org))
   - หรือรันคำสั่ง `node serve.js` แล้วเปิด http://localhost:5555 ด้วย **Chrome** หรือ **Edge**
3. ถ้าต้องการใช้แบบโปรแกรมบนเดสก์ท็อป ให้กดไอคอน “ติดตั้งแอป” ในแถบที่อยู่ของ Chrome (หลังติดตั้งแล้วใช้ได้แม้ไม่มีเน็ต)
4. เสียบสายเข้ารถแล้วเปิดกุญแจ ไม่ต้องติดเครื่อง
5. กด **เชื่อมต่อ** → **สาย USB / COM Port** → เลือกพอร์ต
6. ถ้ายังไม่มีรถ ให้เลือก **ECU จำลอง** เพื่อลองทุกเมนูก่อน

ถ้าจะเอาขึ้นเว็บให้ลูกค้าใช้ ต้องเป็น https (เช่น GitHub Pages) เพราะ Web Serial ไม่ทำงานบน http ทั่วไป ยกเว้น localhost

## โครงสร้าง

- `js/honda.js` — โปรโตคอล Honda K-line: เฟรม, checksum, ตารางข้อมูล, รหัส DTC
- `js/link.js` — สายจริง (Web Serial: wake-up, ตัด echo ของ K-line) และ ECU จำลอง
- `js/app.js` — หน้าจอทั้งหมด
- `test/honda.test.js` — ทดสอบโปรโตคอล (`node test/honda.test.js`)

## เพิ่มรุ่นกล่อง / เปิด Flash

ส่งข้อมูลเหล่านี้มา:

- รหัสบนกล่อง ECU (เช่น `38770-K0W-T01`)
- ไฟล์ “สำรองตาราง” จากเมนู Recovery
- Terminal log ตอนที่เครื่องสแกน/เครื่องจูนตัวอื่นคุยกับกล่อง (ถ้ามี)
