    3. 
        
  3. ลากเมาส์ขวา = หมุนดู · ล้อเมาส์ = ซูม · ผิดกด Ctrl+Z

🖼 เทียบลาย / ฟิล์มในร้าน

      

      
ความเข้ม

      
เอารูปลาย/ฟิล์มจากไฟล์เกมมาเปิด จะเห็นลายทับบนรูปซ้ายและบนรถ · ลากเกาะ UV ให้แผงตรงกับลาย (หน้ารถต้องหันขวา)

    

    

      
🪟 กระจก

      
แบบ

      

      
กระจกเอาสีจากรูปสีใต้ UV ของกระจก: ถ้าใต้กระจกเป็นแดง กระจกจะเป็นสีเดียวกับตัวรถ · ปุ่มนี้ตั้งเฉพาะใต้กระจก ไม่โดนแผงอื่น

    

    

      
⚠ รูปแปลกติดบนรถ (ล้อ / หมากรุก / แถบสี)

      
      

      

      

      

      

      
จุดเล็ก เขียว / น้ำเงิน / ดำ บนรูป = จุดสีของชิ้นที่ทั้งชิ้นใช้สีเดียว (UV ของทั้งชิ้นอยู่จุดเดียว เลยไม่เห็นเส้น) · เขียว = สี 2, น้ำเงิน = สี 3, ดำ = ไม่รับสี · ย้ายไปพร้อมลายเส้น

      

      
    
        
  1. สีม่วงในจอซ้าย = แผงที่ไปทับรูปในชั้น _color หรือทับโซนของเกม (กรอบม่วงมุมล่างซ้าย ทุกคันในเกมมีเหมือนกัน)
    2. 
        
  2. กด 🧽 ล้างรูปออกจากชั้น _color (เก็บบล็อกของเกมไว้)
    3. 
        
  3. แผงที่ยังม่วงอยู่ในกรอบมุมล่างซ้าย → คลิกเกาะนั้นแล้วลากออกนอกกรอบ (ไปที่ว่าง)
    4. 
        
  4. กด ⬇ ดาวน์โหลด
    5. 
      

    

    

      
3. แก้ UV (ไม่บังคับ)

      
เลือกเป็น

      
คลิกเกาะแล้วลาก = ย้าย · ลากกรอบบนที่ว่าง = เลือกหลายเกาะ · Shift = เลือกเพิ่ม
G ย้าย · R หมุนอิสระ (Ctrl = ทีละ 15°) · S ย่อ/ขยาย ตามเมาส์ → คลิก/Enter ยืนยัน · Esc ยกเลิก
ลูกศร = ขยับทีละนิด (Shift = 10 เท่า) · ปุ่มด้านบน ⟳ หมุน 90° / กลับด้าน

      
    
        
  1. ซ้าย = ลาย UV บนรูปมาสก์ · แดง = สี 1 · เขียว = สี 2 · น้ำเงิน = สี 3 · ดำ = ไม่รับสี
    2. 
        
  2. เส้นจาง = ตำแหน่งแผงของ gtv98 (ลาย/ฟิล์มในร้านวาดมาตามนี้) ให้แผงของเราทับแผงเดียวกัน
    3. 
        
  3. คลิก เกาะในจอซ้าย หรือ คลิกบนรถ ในจอขวา → ลาก ย้าย · Shift+คลิก เลือกเพิ่ม
    4. 
        
  4. ปุ่มด้านบน: หมุน / กลับด้าน / ขยาย / ย่อ
    5. 
        
  5. สามเหลี่ยม สีแดง = ลายยืดข้ามรูป (ในเกมเป็นดำ) → กด 🩹 แก้ลายยืดทั้งหมด
    6. 
        
  6. เสร็จแล้วกด ⬇ ดาวน์โหลด
    7. 
      

    

    

      
4. แก้ละเอียดใน Blender (ฟรี)

      

        
        
        
      

      
    
        
  1. Blender: File › Import › Wavefront (.obj) เลือกไฟล์ที่ได้
    2. 
        
  2. เลือกชิ้น › Tab · เลือกขอบที่จะตัด › คลิกขวา Mark Seam · กด U › Unwrap (หรือ U › Smart UV Project)
    3. 
        
  3. หน้าต่าง UV Editing: จัดเกาะให้ทับแผงของ gtv98 บนรูปพื้นหลัง
    4. 
        
  4. File › Export › Wavefront (.obj) ติ๊ก UV Coordinates · ห้ามแก้รูปทรง
    5. 
        
  5. กด ⬆ นำกลับ แล้วดาวน์โหลด
    6.
