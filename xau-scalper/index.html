Binance ใช้ราคา PAXG/USDT แทนทองคำ (1 PAXG = ทองคำ 1 ออนซ์) ไม่ต้องใช้ API key ดึงแท่งเทียนย้อนหลัง 1S/1M/1H/1D จาก REST แล้วรับ bid/ask สดจาก @bookTicker

MetaApi อ่านราคา XAUUSD จากบัญชี MT4/MT5 จริงทุก 1 วินาทีผ่าน REST /symbols/{symbol}/current-price ข้อมูลย้อนหลังจะสร้างจากราคาแรกที่ได้รับ

Custom รองรับ WebSocket ใดก็ได้ที่ส่ง JSON โดยระบุ path ของ bid/ask เช่น data.bid

ถ้าเชื่อมต่อไม่สำเร็จ ระบบจะกลับไปใช้ราคาจำลองอัตโนมัติ การส่งคำสั่งซื้อขายจริงควรทำผ่าน backend ของคุณเอง (ดู BrokerAdapter ในโค้ด) อย่าใส่ Token บัญชีจริงไว้ในหน้าเว็บที่คนอื่นเปิดได้

เครื่องมือนี้เป็นระบบจำลองเพื่อการศึกษา (Paper Trading) ไม่ใช่คำแนะนำการลงทุน การเทรดทองคำด้วย Leverage มีความเสี่ยงสูงและอาจสูญเสียเงินทุนทั้งหมด
